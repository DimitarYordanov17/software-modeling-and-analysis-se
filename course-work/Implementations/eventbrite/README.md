Име на проекта:

Event Management Platform (по структурата на EventBrite)– Диаграми + Data Warehouse + Power BI

Кратко описание на проекта

Проектът представлява проста система за управление на събития. Включва:

Релационна база данни

Концептуални, логически и физически диаграми.

Data Warehouse схема (star-schema) с измерения и три факт таблици.

Примерни данни за тестове.

Power BI репорт с три визуализации – приходи, продадени билети и събития по градове.

Базата поддържа потребители, роли, събития, локации, категории, билети и плащания. Добавени са и примерни функции, процедура за продажба на билети и тригер за проверка на капацитет.

Инструкции за инсталация
1) Инсталиране на SQL Server

Нужен е Microsoft SQL Server + SQL Server Management Studio (SSMS).

2) Създаване на база

Стартирайте SSMS → New Query → изпълнете целия предоставен SQL скрипт:

01_database_script.sql


Той автоматично създава всички таблици, връзки, функция, процедура, тригер и тестови данни.

3) Отваряне на диаграмите

В папката /diagrams има всички draw.io файлове:

Chen Model

Logical Crow’s Foot

Physical

DW Dimensions

Fact диаграмите


4) Power BI

Отворете файла:

EventBrite.pbix


Ако базата е стартирала локално, натиснете Refresh, за да зареди данните от SQL Server.

В отчета има 3 визуализации:

Общо приходи по събитие

Брой продадени билети по категории

Събития по градове

Инструкции за стартиране

Уверете се, че SQL Server LocalDB/Engine е пуснат.

Отворете Power BI и натиснете Refresh.

Диаграмите са само за документация и не изискват стартиране. Тоест може да прегледате снимките
